## API / UI 自动化

### 9. 商品 API 冒烟

```text
@api-skills/执行/SKILL.md
@templates/seckill_api_smoke.md

确认 spec 与 seckill_finance_system 路由一致，并说明如何设置 TEST_USERNAME/TEST_PASSWORD。
```

### 10. 认证接口套件

```text
./generate.sh templates/seckill_api_auth.md
./run_pytest.sh output/seckill_api_auth.py -v
```

### 11. OpenAPI 标准流水线

```text
@api-skills/执行/references/openapi_pipeline.md

从 OpenAPI 生成 cases 草稿（H/E/X），评审后转 spec 再 pytest。
```

```bash
python3 codegen/openapi_to_cases.py -i openapi.json -o output/cases_draft.json \
  --base-url http://your-server:5001 --auth-profile templates/auth_profiles/generic_rest.yaml
python3 codegen/testcase_to_api_spec.py -i output/cases_draft.json -o templates/imported_api.md
./generate.sh templates/imported_api.md
```

### 12. 功能用例转 UI 自动化

```text
@testcase-skills/UI精简/SKILL.md

产出 output/seckill_auth_ui_cases.md
```

```bash
python3 codegen/md_cases_to_ui_spec.py \
  -i output/seckill_auth_ui_cases.md \
  -o templates/ui_from_cases.md \
  --base-url http://your-server:5000

```
