# 秒杀财务系统 · 测试范围 In / Out

### In-Scope（本轮要测）

| 模块 | 具体项 |
|------|--------|
| 认证 | 注册、登录、Profile、401/重复注册 |
| 商品（可选） | 列表匿名、管理员 POST 创建 |
| 秒杀（可选） | 活动列表、下单、Redis 预热 |

| 模块 | 原因 |
|------|------|
| 采购 / 销售 / 报表 | 本轮迭代未改 |

| 压测 1w 并发 | 无性能环境 |

### 冻结区

- 用户注销仅客户端清 JWT，不测服务端会话表（与 PRD 一致时）。
