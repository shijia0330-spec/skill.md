## 1. 环境拓扑（示例表）

| 环境 | 用途 | 访问 | 数据 | 负责人 |
|------|------|------|------|--------|
| local | 开发自测 | your-server:5001 | 本地 Docker | 开发 |
| test | 测试主环境 | （内网 URL） | 独立库；可回滚 | 测试+运维 |
| staging | （可选）预发 | | 近生产脱敏 | 运维 |

**REST 演示**：MySQL + Redis + Flask `http://your-server:5001`。

## 2. 依赖服务检查清单

| 依赖 | 场景 | 不可用时的方案 |
|------|----------|----------------|
| MySQL | 用户/订单/活动 | 阻塞；不开始测试 |
| Redis | 库存预热/扣减 | 标 T-xx；或仅测非模块 |
| JWT 密钥 | 鉴权 | 与环境配置一致 |

## 4. 测试数据策略

### 4.1 账号矩阵

| 角色 | 用途 | 准备方式 |
|------|------|----------|
| admin | 配置活动、商品 | SQL 种子 / 注册脚本 |
| developer | 下单 | 注册接口 |
| 无 Token | 401 场景 | 不带头 |

### 4.2 业务数据

| 数据 | 说明 |
|------|------|
| 普通商品 SKU | 至少 2 个 SKU |
| 活动 | UPCOMING / ACTIVE / ENDED 各 1 个（若范围包含） |
| Redis 库存 | prepare-stock 后 key 可查 |

### 4.3 清理与隔离

- 每轮测试前：是否清 Redis  key。  
- 订单数据：按测试轮次隔离或标记 `test_run_id`。  
- 生产数据：**禁止**直接用于压测；脱敏规则按公司规范。
