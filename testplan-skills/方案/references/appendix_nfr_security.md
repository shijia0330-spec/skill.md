## 1. 触发条件

- PRD 写明安全/权限/合规  
- 处理订单、资金、个人信息  
- 技术文档含 JWT/RBAC  

无触发 → 安全列可标「—」，文内写原因。

## 2. 方案 §3.2 写法（非用例）

| 类别 | 策略深度 | 方法 |
|------|----------|------|
| 认证 | L2 | 无 Token 401；错密 401 |
| 授权 | L2 | developer 调 admin 403 |
| 注入 | L1 | 商品 name XSS 抽查（若有输入） |
| 敏感信息 | L1 | 500 无堆栈；响应无 password_hash |
| 暴力破解 | T-xx 或 — | PRD 有限流才写；否则待澄清 |
