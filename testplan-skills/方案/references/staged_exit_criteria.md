# 分阶段准出 — 参考指标 vs 硬性指标

源 PRD/Excel 常只有功能任务名、少数性能数字，**不写**「哪一里程碑卡质量」。多模块进销存方案须在 §7 **显式分层**，并在追溯表标来源。

---

## 1. 何时用分阶段准出

| 信号 | 处理 |
|------|------|
| 质量/性能指标依赖环境、压测数据、调优 | M1 功能通，M4 数字准出 |
| 测试人力 << 用例资产 | M1 非阻塞项列表 |
| Excel 只有「秒杀压测」无阈值 | T-15 + M4 硬性 |
| 性能备注有数字但未定义负载 | T-03/T-04 澄清会 |

---

## 2. 写法模板

### M1 准出（联调）

```markdown
### P2.M1 阶段准出

> **M1 成功标准（对外口径）**：P0 主路径全通 + ≥3 E2E + P0 缺陷=0 + 自动化 collect-only 通过

- [ ] §2.1 P0 模块主路径已执行
- [ ] 跨模块 E2E ≥N 场景通过（登录→商品→库存）
- [ ] 自动化冒烟本地可跑 + collect-only ≥预期条数

> **M1 非阻塞项**：秒杀压测、财务对账深度、长稳 — 抽样验证，**不作为 M1 阻塞准出**（完整指标见 P2.M4）
```

### M4 准出（SLT）

```markdown
### P2.M4 SLT 准出

- [ ] 秒杀下单 P99≤__（T-03）
- [ ] 秒杀服务长稳 __h、CPU≤__%（T-04）
- [ ] 财务对账样本执行完毕，达 T-15 或书面豁免
- [ ] HA/容灾有限演练（T-05，非全量混沌）
```

---

## 3. 常见「非阻塞 → 硬性」映射

| 专项 | M1 | M2～M3 | M4 |
|------|-----|--------|-----|
| 秒杀下单 | P0 主路径 | 限购/库存边界试跑 | T-03 硬性 |
| 库存一致性 | 单 SKU 冒烟 | P1 抽样 | T-15 硬性或豁免 |
| 秒杀下单 P99 | 单用户冒烟 | 可选抽样 | T-03 硬性 |
| 秒杀长稳 | 不跑 | 不跑或短跑 | T-04 硬性 |
| 缓存/Redis | 单节点冒烟 | P1 抽样 | T-12 约定 |
| 自动化 CI | 本地 pytest | PR 门禁 T-09 | 回归绿 |

**注意**：M2～M3 若无单独 §7 清单，正文写「执行阶段见 §4.2，准出口径以 M4 为准」，避免读者误以为 M3 也卡 P99 数字。

---

## 4. 与 Excel 的关系

- Excel 里程碑（P2.M1 / P2.M4 SLT）→ 对齐方案 §7 两套准出。  
- Excel 测试任务备注（如 P99≤2s）→ 进 T-xx 或 A.1，**不默认等于 M1 准出**。  
- 测试扩展的分层准出 → 附录 H 或 §4.2 说明块标注「测试策略扩展」。

---

## 5. 计划 Skill 引用

每个里程碑 **退出准则** 必须可观测：

| 里程碑 | 退出准则示例 |
| M1-S3 | 秒杀下单主路径绿；P0 用例初版 ≥10 条 |
| M3-补测 | P1 用例 ≥20 条执行；财务对账 ≥1 场景通 |
| M4-SLT | 方案 §7 P2.M4 全条 + 评审签字 |

最后里程碑退出准则 ⊇ 方案 M4 核心条。

---

## 6. 评审检查

- [ ] M1 非阻塞项列表与 §4.2 专项阶段一致  
- [ ] M4 每条硬性指标有 T-xx 或 Excel 备注出处  
- [ ] 未关闭 T-xx 对准出的影响在 §7 或附录 A 说明  
- [ ] 产品知晓「M1 不卡 P99 数字」若为测试扩展
