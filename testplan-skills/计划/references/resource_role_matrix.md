# 资源与角色职责矩阵

---

## 1. 角色定义

| 角色 | 典型人数 | 核心职责 |
|------|----------|----------|
| **测试负责人** | 1 | 方案/计划、资源协调、准出签字 |
| **功能测试** | 1～N | 用例编写执行、缺陷验证 |
| **SDET** | 0～1 | API 自动化、冒烟脚本 |
| **开发** | 按需 | 修复、联调、技术澄清 T-xx |
| **产品** | 1 | 需求澄清、验收、T-xx Owner |
| **运维** | 0～1 | 环境、中间件、发布配合 |
