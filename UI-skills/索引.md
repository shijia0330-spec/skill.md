## 一条常见流水线

页面截图/URL → **DOM 扫描**（缓存） → **选择器注册表** → **元素识别** → **Playwright 脚本生成** → **执行** → 元素变了 **自愈兜底** → 报告。

---

## 核心能力（Web 端）

| 能力 | 位置 | 说明 |
|------|------|------|
| 七种定位 + L2 + L3 | `执行/references/locator_strategy_web.md` + `locator_healer.py` | Web Playwright 专用；L3 按 input type 兜底 |
| DOM 扫描缓存 | `分析/00_DOM扫描.md` | 基于 URL MD5 缓存，TTL 默认 1 小时 |
| 选择器注册表 | `分析/05_选择器注册表.md` | 跨文件共享定位器，POM 引用 registry_key |
| 自愈 Skill | `自我修复/SKILL.md` | 流程、日志、环境变量 |
| 视频录制 | `执行/SKILL.md` | 执行过程录屏，失败自动截图 |
| 登录前置 | `执行/SKILL.md` | 非登录用例自动添加登录步骤 |
| Allure 报告 | codegen/run_spec.py | 自动附加 title/tag/截图 |
