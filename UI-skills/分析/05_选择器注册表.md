# 选择器注册表

从 DOM 扫描结果提取定位器，存入统一的 `output/selectors.json`。所有测试文件从注册表读取定位器，不再碎片化。

**解决什么问题：**
POM 类在每个测试文件独立生成，定位器无法共享。注册表让所有测试文件引用同一份定位器定义，DOM 扫描结果自动导入。

**放在流程的哪个位置：**
```
DOM 扫描 → 导入注册表 → spec 引用 registry_key → 生成 POM 类 → 执行测试
```

---

## 快速使用

```bash
# 1. 扫描页面
python3 UI-skills/分析/scripts/scan_page_dom.py \
  --url http://your-server:8080/login \
  --out output/dom-scan/dom_login.json

# 2. 导入注册表
python3 UI-skills/分析/scripts/selector_registry.py import output/dom-scan/dom_login.json

# 3. 查看注册表
python3 UI-skills/分析/scripts/selector_registry.py list

# 4. 查询选择器
python3 UI-skills/分析/scripts/selector_registry.py query loginPage placeholder:Username

# 5. 合并多个扫描结果
python3 UI-skills/分析/scripts/selector_registry.py merge \
  output/dom-scan/dom_login.json \
  output/dom-scan/dom_dashboard.json

# 6. 导出注册表
python3 UI-skills/分析/scripts/selector_registry.py export --out output/selectors.json
```

## 注册表结构

```json
{
  "version": 1,
  "pages": {
    "登录": {
      "url": "http://your-server:8080/login",
      "elements": {
        "placeholder:Username": {
          "hints": {
            "placeholder": "Username",
            "type": "input"
          },
          "tag": "input",
          "text": "",
          "disabled": false,
          "source": "dom_login.json"
        },
        "placeholder:Password": {
          "hints": {
            "placeholder": "Password",
            "type": "input"
          },
          "tag": "input",
          "text": "",
          "disabled": false,
          "source": "dom_login.json"
        },
        "role:button:text:登录": {
          "hints": {
            "role": "button",
            "type": "button"
          },
          "tag": "button",
          "text": "登录",
          "disabled": false,
          "source": "dom_login.json"
        }
      }
    }
  }
}
```

**选择器 key 生成规则**（优先级从高到低）：
1. `testid:{data-testid}` — 最稳定
2. `id:{element_id}` — 次稳定
3. `name:{name属性}` — 表单字段常用
4. `placeholder:{placeholder}` — 输入框常用
5. `role:{role}:text:{文本}` — 按钮/链接常用

## 在 spec 中引用

```yaml
kind: ui_pytest_playwright
base_url: http://your-server:8080
page_objects:
  - name: loginPage
    path: /login
    registry_key: loginPage  # 注册表页面名
    elements:
      - name: username
        registry_key: placeholder:Username  # 从注册表加载
      - name: password
        registry_key: placeholder:Password
      - name: submit
        registry_key: role:button:text:登录
flows:
  - name: 登录测试
    steps:
      - action: ensure_logged_in
        path: /login
        username: admin
        password: admin123
```

生成的 POM 类自动从 `output/selectors.json` 加载定位器：

```python
class LoginPage:
    _SELECTORS = _load_selectors_from_registry("loginPage")

    def get_username(self):
        hints = self._SELECTORS.get("placeholder:Username")
        loc, _ = _ui_healer.resolve_locator(self.page, LocatorHints(**hints))
        return loc
```

**注册表优先**：如果元素同时指定了 `registry_key` 和手写定位器（testid/role/label），注册表优先。

## 与 DOM 扫描的衔接

| 步骤 | 命令 | 输出 |
|------|------|------|
| DOM 扫描 | `scan_page_dom.py --url ...` | `output/dom-scan/dom_*.json` |
| 导入注册表 | `selector_registry.py import ...` | `output/selectors.json` |
| spec 引用 | `registry_key: placeholder:Username` | 生成 POM 代码 |

---

## 参数说明

| 命令 | 参数 | 说明 |
|------|------|------|
| `import` | `dom_file` | DOM 扫描 JSON 文件路径 |
| `import` | `--registry` | 注册表文件路径（默认 `output/selectors.json`） |
| `export` | `--out` | 导出路径（默认 `output/selectors.json`） |
| `query` | `page` | 页面名 |
| `query` | `element` | 元素 key（支持模糊匹配） |
| `merge` | `dom_files` | 多个 DOM 扫描文件（空格分隔） |
