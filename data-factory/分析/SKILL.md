# 数据分析

从用例清单提取数据需求，列出需要什么数据。

---

## 做 / 不做

| 做 | 不做 |
|----|------|
| 从用例清单提取数据需求 | 生成注入脚本（走执行/SKILL.md） |
| 数据分类（基础/业务/边界/安全） | 清理数据（走清理/SKILL.md） |
| 列出数据清单 | |

---

## 数据分类

| 类别 | 说明 | 典型例子 |
|------|------|---------|
| 基础数据 | 系统运行必需 | 用户账号、角色、权限配置 |
| 业务数据 | 测试功能用 | 秒杀活动、商品、订单、Redis 库存 |
| 边界数据 | 测极限和异常 | 超长文本、超大文件、空值 |
| 安全数据 | 测注入和攻击 | SQL注入字符串、XSS 脚本 |

---

## 工作流程

### Step 1：读取用例清单

从 testcase-skills 产出的用例中提取数据依赖：

```
用例 TC-001：正常登录 → 需要：1 个正常用户账号
用例 TC-002：密码错误 → 需要：1 个正常用户账号
用例 TC-003：未注册登录 → 不需要预置数据（跳过）
用例 TC-004：秒杀下单 → 需要：1 个商品（库存>0）、1 个用户
```

### Step 2：数据清单

输出表格：

| 数据 | 数量 | 用途 | 创建顺序 |
|------|------|------|----------|
| 用户 admin | 1 | 管理操作 | 1 |
| 用户 customer_01~03 | 3 | 秒杀下单 | 2 |
| 商品 A（正常库存） | 1 | 秒杀 | 3 |
| 商品 B（库存=0） | 1 | 边界测试 | 3 |
| 商品 C（名称超长） | 1 | 边界测试 | 3 |

### Step 3：关联关系

| 数据 A | → | 数据 B | 关联方式 |
|--------|---|--------|----------|
| 用户 | → | 订单 | user_id 外键 |
| 商品 | → | 订单 | product_id 外键 |
| 活动 | → | 商品 | activity_id 外键 |

---

## 输出

输出 `数据需求_<模块>_<日期>.md`。
