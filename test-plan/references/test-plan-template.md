## 3. 测试策略

### 3.1 功能测试

| 测试方法 | 说明 | 工具 |
|---------|------|------|
| 场景法 | 业务流程场景覆盖 | pytest / 手工 |
| 等价类 | 输入数据分类 | pytest |
| 边界值 | 边界条件验证 | pytest |
| 错误猜测 | 基于经验预测缺陷 | 手工 |

### 3.2 接口测试

| 测试类型 | 说明 | 工具 |
|---------|------|------|
| 冒烟测试 | 核心接口可用性 | pytest |
| 回归测试 | 接口功能验证 | pytest + requests |
| 契约测试 | API 契约验证 | pytest + OpenAPI |

### 3.3 性能测试

| 测试类型 | 目标 | 工具 | 指标 |
|---------|------|------|------|
| 基准测试 | 单用户响应时间 | JMeter | RT < 200ms |
| 负载测试 | 预期并发量 | JMeter | RT < 500ms, 错误率 < 1% |
| 压力测试 | 系统极限 | JMeter | 找到瓶颈点 |
| 稳定性测试 | 长时间运行 | JMeter | 24h 无内存泄漏 |

### 3.4 安全测试

| 测试项 | 说明 | 工具 |
|--------|------|------|

| SQL 注入 | 输入验证 | OWASP ZAP |
| XSS | 跨站脚本 | OWASP ZAP |
| CSRF | 跨站请求伪造 | 手工 |

### 3.5 UI 测试
