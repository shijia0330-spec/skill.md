# PRD 节选：用户认证（秒杀财务系统）

> 演示用迷你需求，对应 `seckill_finance_system/需求文档.md` §2.1。完整系统另含商品、秒杀、财务模块。

## 2.1 用户认证与权限管理

### 2.1.1 用户注册

- 新用户通过用户名、密码、邮箱注册。
- 用户名唯一；密码 Werkzeug 哈希存储；默认角色 `customer`。
- 接口：`POST /api/auth/register`

| 字段 | 规则 |
|------|------|
| username | 必填，1～50 字符，字母数字下划线中划线，唯一 |
| password | 必填，至少 6 字符 |
| email | 可选，最大 100 字符，邮箱格式 |

重复用户名返回错误；注册成功返回 201。

### 2.1.2 用户登录

- 校验用户名密码；成功返回 JWT，有效期 24 小时。
- 接口：`POST /api/auth/login`
- 错误密码返回 401。

### 2.1.3 用户信息

- 已登录用户查询个人信息。
- 接口：`GET /api/auth/profile`（或 `GET /api/user/me`）
- 未带 Token 返回 401。

### 2.1.4 权限

| 角色 | 能力 |
|------|------|
| customer | 浏览商品、参与秒杀、查自己的订单 |
| admin | 商品管理、采购销售、财务管理等 |

管理员账号示例：`admin` / `admin123`（测试环境可通过 `POST /api/test/init` 初始化）。
