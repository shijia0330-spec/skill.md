# 测试用例说明书

| 项目 | 说明 |
|------|------|
| 对应需求 | [`需求文档.md`](需求文档.md)（商品管理 · 秒杀财务演示系统） |
| 规范来源 | `testcase-skills/生成`（生成测试点）；入库 JSON 时 `test_case` / `test_case_bdd`；`test_steps` 每项为 `{"step","result"}`（**不得**使用 `expected_result`） |
| 用途 | 评审与执行、或经项目适配后传入 `batch_create_test_cases_tool` |

---

## 1. 需求追溯（业务段落 → 覆盖）

| 需求段落 | 用例覆盖要点 |
|----------|----------------|
| 浏览在售商品列表 | 仅展示在售；含名称、当前价（含秒杀态）、图、简述；不含已下架 |
| 查看商品详情 | 登录可访问完整信息；未登录应被引导登录 |
| 新增商品 | 管理员专属；名称+常规价必填；可选描述/库存/秒杀字段；创建后默认在售；秒杀库存>0 触发后台准备；校验与错误提示 |

## 5. 自检（对照 `testcase-skills/生成` 质量要求）

- **独立性**：用例尽量独立；L-01、L-03、A-04 依赖数据或环境，已在 `preconditions` 写明。  
- **预期可判定**：步骤写清界面或观测结果，避免仅写「系统正常」。  
- **优先级**：鉴权与列表状态过滤为 critical/high；展示与性能为 medium/low。  
- **标签**：统一 `products` 及 `list` / `detail` / `create` / `seckill` / `validation` / `rbac` / `auth` 等子标签，便于检索与统计。
