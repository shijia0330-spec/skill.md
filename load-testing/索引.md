# 压测 — 文件怎么串

**版本**：2026-06

从「目标接口」到「压测报告」，文件按 **分析 → 规划 → 执行 → 报告** 读最顺。

---

## 分析

| 文件 | 干什么 |
|------|--------|
| [分析/SKILL.md](分析/SKILL.md) | 识别压测目标、接口清单、性能指标 |

## 规划

| 文件 | 干什么 |
|------|--------|
| [规划/SKILL.md](规划/SKILL.md) | 设计压测场景、并发模型、数据策略 |

## 执行

| 文件 | 干什么 |
|------|--------|
| [执行/SKILL.md](执行/SKILL.md) | **默认 k6** 生成脚本并执行；JMeter 用 `./generate_jmeter.sh` |

## 报告

| 文件 | 干什么 |
|------|--------|
| [报告/SKILL.md](报告/SKILL.md) | 解读指标 / 截图识别 / Markdown 或 HTML 报告 / 瓶颈定位 |
| [报告/references/screenshot-tools-guide.md](报告/references/screenshot-tools-guide.md) | JMeter、k6、云压测截图读图 |

| [报告/assets/performance-report-template.html](报告/assets/performance-report-template.html) | HTML 报告模板 |
| [references/bottleneck-checklist.md](references/bottleneck-checklist.md) | 瓶颈检查清单 |
| [references/k6-template.js](references/k6-template.js) | k6 可运行模板 |
| [references/seckill_load.jmx](references/seckill_load.jmx) | JMeter 可运行模板 |
| [references/jmeter-template.md](references/jmeter-template.md) | JMeter 结构说明 + `./generate_jmeter.sh` |

## 一条常见流水线

压测目标 → **分析** → **规划** → **执行** → **报告**

只有截图、未跑本包脚本时，可直接 `@报告/SKILL.md` 走轻量分析入口。
