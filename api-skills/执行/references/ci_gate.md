# CI 门禁

**合并代码前先过四道安检，不过就别想上线。**

---

## 做 / 不做

| 做 | 不做 |
|----|------|
| 四维度阈值检查（性能/安全/质量/断言） | 执行测试（走 api-skills） |
| 环境差异化配置（开发/测试/生产） | 修代码（走开发） |
| 自动回滚 | |

---

## 为什么需要 CI 门禁

| 没有门禁 | 有门禁 |
|----------|--------|
| 代码合并了才发现性能有问题 | CI 阶段就检查，超标直接拦 |
| 每个项目重新配规则 | 三套预设（dev/staging/prod） |
| 门禁失败只能人工通知 | 自动回滚 |

**生活例子**：像过安检——行李超重、带违禁品，在入口就被拦住。

---

## 四维度阈值

### 性能维度

| 参数 | 开发环境 | 测试环境 | 生产环境 |
|------|----------|----------|----------|
| 平均响应时间 | ≤ 500ms | ≤ 300ms | ≤ 200ms |
| P95 响应时间 | ≤ 1000ms | ≤ 800ms | ≤ 500ms |
| P99 响应时间 | ≤ 2000ms | ≤ 1500ms | ≤ 1000ms |
| 失败率 | ≤ 5% | ≤ 2% | ≤ 1% |
| 错误率 | ≤ 3% | ≤ 1% | ≤ 0.5% |
| QPS | ≥ 50 | ≥ 100 | ≥ 500 |

### 安全维度

| 参数 | 开发环境 | 测试环境 | 生产环境 |
|------|----------|----------|----------|
| 严重漏洞 | ≤ 2 | ≤ 0 | 0 |
| 高危漏洞 | ≤ 5 | ≤ 2 | 0 |
| 中危漏洞 | ≤ 10 | ≤ 5 | ≤ 5 |

### 代码质量维度

| 参数 | 开发环境 | 测试环境 | 生产环境 |
|------|----------|----------|----------|
| 代码覆盖率 | ≥ 60% | ≥ 80% | ≥ 90% |
| 代码异味 | ≤ 20 | ≤ 10 | ≤ 5 |
| 测试通过率 | ≥ 80% | ≥ 95% | ≥ 98% |

### 断言维度

| 参数 | 说明 |
|------|------|
| 关键断言通过率 | 核心业务断言 100% 通过 |
| 业务规则断言 | 业务规则检查全部通过 |

---

## 门禁流程

```
提交代码 → CI 开始跑
  → 第一步：压测，看 P99 响应时间 ≤ 1000ms？
  → 第二步：扫漏洞，看高危漏洞 ≤ 0 个？
  → 第三步：看覆盖率 ≥ 90%？
  → 第四步：看测试通过率 ≥ 98%？
  ↓
全部通过 → [OK] 绿码放行，继续部署
有一项失败 → [FAIL] 红码拦截，并自动回滚
```

---

## 行为选项

| 选项 | 说明 | 适用环境 |
|------|------|----------|
| [FAIL] 超阈值时失败 | 超过阈值直接算不通过 | 生产 |
| [WARN] 超阈值时警告 | 超过阈值只警告，不阻断 | 开发 |
| 🔄 自动回滚 | 不通过时自动触发回滚 | 生产 |

## 可执行引擎

**方案 B 已实现**：`ci-gate/` 目录包含可执行的 CI 门禁代码。

### 快速使用

```bash
# 生产环境检查
cd ci-gate/scripts
python3 ci_gate.py --env prod --metrics metrics.json

# 带自动回滚
python3 ci_gate.py --env prod --auto-rollback
```

### Python 调用

```python
from quality_gate import create_checker

checker = create_checker("prod", auto_rollback=True)
result = checker.check(metrics, "生产环境门禁检查")
print(result.report)
```

## 输出格式

| 格式 | 说明 |
|------|------|
| text | 终端输出，适合 CI 日志 |
| HTML | 可视化报告，适合邮件发送 |
| Markdown | 适合贴到钉钉 |

### 报告示例

```markdown
# CI 门禁报告

## 检查结果：[FAIL] 不通过

| 维度 | 阈值 | 实际值 | 结果 |
|------|------|--------|------|
| P95 响应时间 | ≤ 500ms | 620ms | [FAIL] |
| 严重漏洞 | 0 | 0 | [OK] |
| 代码覆盖率 | ≥ 90% | 85% | [FAIL] |
| 测试通过率 | ≥ 98% | 99% | [OK] |

## 失败项
1. P95 响应时间 620ms > 500ms
2. 代码覆盖率 85% < 90%
```

## CI/CD 集成

### GitHub Actions

```yaml
- name: CI 门禁检查
  run: |
    ./ci-gate check \
      --env production \
      --perf-file results.json \
      --security-report scan.json \
      --coverage 85 \
      --test-pass-rate 0.99
```

### GitLab CI

```yaml
quality_gate:
  stage: deploy
  script:
    - ./ci-gate check --env production --auto-rollback
```
