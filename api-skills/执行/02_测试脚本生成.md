# 把用例落成 pytest — api_lib 委托版

目标：**一份（或一组）Python 脚本**，CI 里 `pytest` 直接跑。本包由 `codegen/run_spec.py` 生成，**HTTP 执行委托 `codegen/api_lib/`**，不再内联大段 requests 样板代码。

---

## 1. 原则上几条

1. **薄生成物**：生成文件只含 fixture + `test_*` 壳，业务逻辑在 `api_lib.run_case` / `run_scenario` / `run_batch`。  
2. **变量命名**：spec 里 case `id` 会转成 `test_*` 函数名，只用字母数字下划线。  
3. **先断言再提取**：`run_case` 内先校验 `expect_status`，再写 `extract_vars` 入 `VariablePool`。  
4. **断言**：状态码 + `expect_json_subset` / `expect_json_schema` / `assertions[]`，由 `api_lib.assertions` 统一执行。  
5. **环境**：`BASE_URL`、账号从 `TEST_BASE_URL` / `TEST_USERNAME` / `TEST_PASSWORD` 读取。

---

## 2. 输入是什么

结构化用例列表（`cases[]` / `scenarios[]` / `batch`）写在 spec YAML frontmatter；可由：

- 手写 `templates/api_*.md`
- `testcase_to_api_spec.py` 从 cases JSON 转 spec
- `openapi_import` / `openapi_to_cases.py` 从 OpenAPI 产出

## 3. 生成物长什么样

```python
# Auto-generated by spec runner (api_lib)
from api_lib import VariablePool, run_batch, run_case, run_scenario
from api_lib.http_client import create_anon_session, create_api_session

BASE_URL = os.environ.get('TEST_BASE_URL', "http://your-server:5001")

@pytest.fixture(scope='session', autouse=True)
def _setup_test_data():
    from api_lib.setup_hook import run_api_setup
    run_api_setup(BASE_URL, _SETUP_CFG)

@pytest.fixture(scope='session')
def var_pool():
    return VariablePool()

@pytest.fixture(scope='session')
def api_session(var_pool):
    s = create_api_session(BASE_URL, _AUTH, var_pool, use_healing=True)
    yield s
    s.close()

def test_tc_001(api_session, var_pool):
    run_case(api_session, var_pool, _CASE_0, BASE_URL, timeout_default=30)
```

生成物头部会自动插入 `sys.path` bootstrap，支持从 `output/` 直接 `pytest`；推荐仍用根目录 `./run_pytest.sh`（已设 `PYTHONPATH=codegen`）。

## 6. 声明式 spec：`cases` 与 `scenarios`

| 字段 | 生成行为 | 运行时 |
|------|----------|--------|
| **`cases[]`** | 每条 → 独立 `test_*` | `api_lib.run_case` |
| **`scenarios[]`** | 每条 → `test_scenario_*` | `api_lib.run_scenario`（多步 + `capture`） |
| **`batch`** | `test_batch_execute` | `api_lib.run_batch`（拓扑 + 并发 + 进度 JSONL） |

**`scenarios` 约定**：

- **`capture`**：上一步响应 JSON 按路径取值 → 写入 `VariablePool`  
- **`path` / `json_body` / `headers`**：支持 `${var}`、`{{var}}`、`{ctx}`、`__ENV__:KEY`（见 `api_lib.resolver`）  
- **`no_auth: true`**：该步用 `api_session_anon`（匿名 Session）

模板：`templates/api_scenario_register.md`、`templates/api_chain_vars.md`。

## 7. 测试数据前置（`setup`）

由 `api_lib.setup_hook.parse_api_setup` 解析，生成 autouse fixture `_setup_test_data`：

| spec 写法 | 行为 |
|-----------|------|
| **不写 `setup`** | 默认 `test_init`：`POST /api/test/init` |
| `setup: test_init` | 同上，可配 `path` / `json_body` |
| `setup: none` | 不铺底 |
| `setup: { kind: data_factory, script: output/data_factory.py }` | 跑造数脚本 |

运行时：`TEST_SETUP=none` 跳过；`TEST_INIT_PATH` / `TEST_INIT_BODY` 覆盖 init。

**隔离与清理**（`isolation: per_test` 或 `teardown.mode: refs`）：

- `var_pool` / `api_session` scope 降为 `function`  
- 生成 `refs_registry` fixture，用例结束 `RefsRegistry.cleanup_all` 精确 DELETE

## 8. 变量池与高级能力（api_lib）

| 能力 | spec 写法 | api_lib 实现 |
|------|-----------|--------------|
| 跨 case 引用 | `headers: { Authorization: "Bearer ${token}" }` | `VariablePool` + `resolver.resolve_string` |
| 响应提取 | `extract_vars: { token: "$.data.token" }` | `run_case` → `extract_by_path` |
| 失败跳过下游 | `depends_on: [TC-001]` | `topological_sort` + `_check_case_depends` → `pytest.skip` |
| CSV/JSON 驱动 | `batch.data_source: { type: csv, path: output/users.csv }` | `load_data_rows` + `run_batch` |
| 登录入池 | `auth: { type: bearer_login, ... }` | `create_api_session` 登录后写 token |
| 401 刷新 / 重试 | `healing: true` 或 `healing: { max_retries: 3 }` | `HealingSession` |
| 断言扩展 | `assertions: [{ type: json_path, ... }]` | `ASSERTION_REGISTRY` |

详见 `执行/references/variable_pool.md`、`执行/SKILL.md` §变量池与链式执行。

## 9. 子模块索引（codegen/api_lib/）

| 模块 | 职责 |
|------|------|
| `executor.py` | `run_case` / `run_scenario` / `run_step` |
| `http_client.py` | `create_api_session`、HealingSession |
| `variable_pool.py` | 变量池读写 |
| `resolver.py` | `${}` / `__ENV__` 解析 |
| `batch.py` | 拓扑排序、批量执行、CSV 合并 |
| `assertions.py` | 状态码、JSON subset/schema、响应时间 |
| `setup_hook.py` | test_init / data_factory 铺底 |
| `refs_registry.py` | 资源登记与精确清理 |

生成器入口：`codegen/run_spec.py` → `render_api_pytest`；schema 说明：`python3 codegen/run_spec.py --print-schema`。
