## 一条常见流水线

用户需求或契约 → **解析 + 依赖图** → **计划与样本数据** → **用例 → 脚本** → CI 跑 → 挂了 **自愈或记缺陷**。

缺陷登记走仓库里的 **bug-reporter**，不在这张表里重复写。

## 核心能力

| 能力 | 位置 | 说明 |
|------|------|------|
| 依赖图推断 | 分析/SKILL.md | 4 种策略自动推断接口调用链 |
| 变量池 + 链式执行 | 执行/SKILL.md | `${token}` 自动注入，失败跳过下游 |
| 故障自愈 | 自我修复/SKILL.md | 401 刷新 Token、500 指数退避 + Jitter |
| OpenAPI 导入 | 分析/04_OpenAPI导入.md | `--import-openapi` 一键生成 spec |
| JSON Schema 校验 | codegen/run_spec.py | `expect_json_schema` 契约断言 |
| 响应时间断言 | codegen/run_spec.py | `expect_max_response_ms` 性能检查 |
| Allure 报告 | codegen/run_spec.py | 自动附加响应体、响应时间 |
| 数据清理 | codegen/run_spec.py | teardown 支持 api_cleanup/refs_cleanup/sql_cleanup |
| refs tracking | codegen/run_spec.py | data_factory 自动保存 Created IDs，精确删除 |
| per-test 隔离 | codegen/run_spec.py | setup/teardown 支持 scope: function |
