# 测试规划 — 范围、策略与节奏

需求还粗、**分析**还没往下拆的时候，先用这篇把**测哪些、大概多久、先动哪块**说清楚，方便排期和拉人。产出给评审会和资源协调用，不是替代具体用例。

---

## 1. 适用边界

**宜用**：

- 新版本发布前需要总体测试方案；  
- 多团队并行，需要统一优先级语言（P0/P1…）；  
- 资源有限，需要风险驱动的裁剪策略。

**可跳过**：

- 单条缺陷验证或极小规模改动且范围已在工单写死。

---

## 2. 规划管线（五段）

### 段 A — 范围锚定

写清楚：**业务模块**、**本轮发布节奏**、**哪些老模块冻结别动**、**外部依赖能不能用**（MySQL、Redis、秒杀演示服务 `http://your-server:5000` 等）。

### 段 B — 风险画像

使用简易评分：`影响面 × 变更频率 × 历史故障密度`。分数高者优先设计深度用例。

### 段 C — 测试类型配比

并不强制固定比例；示例：

| 情形 | 经验配比（可调） |
|------|------------------|
| 核心交易迭代 | 功能 65% / 回归 20% / 性能 10% / 安全 5% |
| 技术债偿还周 | 自动化补洞 50% / 回归 40% / 其它 10% |

### 段 D — 节奏与里程碑

输出 **周粒度** 或 **冲刺粒度** 表格：日期 / 目标 / 退出准则（如「P0 缺陷清零」）。

### 段 E — 资源与工具

人力角色（业务测试 / SDET / 运维联络）、环境窗口、数据筹备责任人。

---

## 3. 输出模板（示例骨架）

```markdown
# 测试规划：<版本号>

## 1. 范围
- In-Scope：……
- Out-of-Scope：……

## 2. 风险热区
| 模块 | 风险说明 | 缓解 |
|------|----------|------|

## 3. 类型配比
- …

## 4. 里程碑
| 周次 | 目标 | 退出准则 |
|------|------|----------|

## 5. 资源
- …
```

---

## 4. 示例切片（秒杀财务系统）

**范围**：仅「秒杀活动配置 → Redis 预热 → customer 下单」；本轮不改采购/销售报表页面。

**风险热区**：Redis 防超卖、活动状态 UPCOMING/ACTIVE/ENDED、admin/customer 越权。

**节奏**：W1 认证+商品 API 冒烟；W2 预热+下单主路径；W3 边界与限购；W4 回归（见 `references/seckill_finance_milestones.md`）。

---

## 5. 出口闸门

- 范围段落为空 → **禁止**进入大规模用例编写。  
- 未指定退出准则 → 默认不可宣称「测试完成」。

---

## 6. 协作接口

| 技能 | 交互 |
|------|------|
| 分析 | 接收粗粒度模块列表 → 输出细分场景 |
| 生成 | 将里程碑映射为用例批次 |
| 评审 | 审阅规划与最终用例集一致性 |

---

## 7. 限制

本 SKILL **不**直接调用落库 API；生成文件或工单的行为由平台适配层完成。
