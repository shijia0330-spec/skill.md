# 通用覆盖矩阵（专业版必扫）

> 矩阵本身与行业无关；打勾时以当前 PRD 为准。本包演示与黄金样例默认 **seckill_finance_system**（商品、秒杀、JWT、Redis）。

本矩阵与 PRD 无关的 **通用测试维度**：只要识别到对应 **触发器**，就必须有测试点，或输出 **「（待澄清）」** 占位检查点。  
**不**据此编造 PRD 未写的业务功能（如不写「编辑商品」除非 PRD/OpenAPI 有写）。

与 `testcase-skills/评审` 覆盖清单对齐；Step 6 须对本矩阵逐项打勾。

---

## 使用方式

对每个功能模块 / 接口 / 页面，在 Step 4 填写下表「触发器」列，勾选「必测项」，生成检查点或 `（待澄清：…）`。

| 列 | 含义 |
|----|------|
| 触发器 | 需求或实现中出现即激活 |
| 必测项 | 至少 1 条检查点 |
| PRD 未写时 | 标待澄清，不静默跳过 |

---

## A. 数据输入与校验（出现表单、请求体、查询参数）

| 触发器 | 必测项 | PRD 未写时 |
|--------|--------|------------|
| 有必填字段 | 仅必填成功；缺每一必填项各 1 条失败 | 标出字段名待确认 |
| 有数值/金额/数量 | 负值拒绝；0 值（允许/拒绝按 PRD）；最小正数 | 0 是否允许标待澄清 |
| 有长度限制或「最大/最小」 | 边界 trio：限-1、限、限+1 | 从 PRD 提取或标待澄清 |
| 有格式要求（邮箱/username/URL 等） | 合法 1 例；典型非法 2～3 例 | 秒杀财务注册见 username、email 规则 |
| 文本字段 | 空字符串；纯空白；超长；中英文+emoji | 长度上限待澄清 |
| 唯一性（名称/编码不重复） | 未占用成功；已占用失败 | PRD 未写则标「是否唯一待确认」 |
| 枚举/下拉 | 每一合法值；1 个非法值 | 枚举表待澄清 |

---

## B. 列表与查询（出现列表、搜索、筛选）

| 触发器 | 必测项 | PRD 未写时 |
|--------|--------|------------|
| 列表展示 | 有数据正常展示；无数据空态不崩溃 | — |
| 状态/类型过滤 | 仅符合过滤条件的数据出现 | 过滤规则以 PRD 为准 |
| 分页（PRD 或 API 有 page/size） | 第一页；末页；page 越界/负数 | 越界行为标待澄清 |
| 排序（若有） | 升序/降序至少各 1 条 | 未写则跳过 |
| 搜索/关键词 | 命中；不命中空结果 | 未写搜索则跳过 |

---

## C. 鉴权与角色（出现登录、管理员、权限说明）

| 触发器 | 必测项 | PRD 未写时 |
|--------|--------|------------|
| 需登录才能用 | 已登录成功；未登录拦截/引导登录 | 401/跳转方式标待澄清 |
| 管理员专属操作 | 管理员成功；普通用户拒绝；未登录拒绝 | 403/无入口标待澄清 |
| 仅匿名可访问（如公开列表） | 未登录可访问；不因缺 Token 失败 | — |

---

## D. 资源标识（出现按 ID 访问详情/更新/删除）

| 触发器 | 必测项 | PRD 未写时 |
|--------|--------|------------|
| 按 ID 读详情 | 合法 ID；不存在 ID（404 或等价） | — |
| 写操作后读 | 创建后可查；与提交字段一致 | — |
| 软删/下架 | 下架后列表不可见；详情行为标 PRD 或待澄清 | 详情是否 404 待澄清 |

---

## E. 时间与状态（出现活动时间、状态机、定时任务）

| 触发器 | 必测项 | PRD 未写时 |
|--------|--------|------------|
| 开始/结束时间 | 未开始、进行中、已结束 各 1 条（预期标待澄清若 PRD 未写） | 必须输出占位检查点 |
| 结束早于开始 | 非法组合拒绝保存 | 未写是否校验则标待澄清 |
| 状态字段（在售/下架等） | 合法迁移；非法迁移拒绝（若 PRD 有） | 状态图待澄清 |
| 次数限制（N 次锁定） | N-1、N、N+1 次 | 从 PRD 提取 N |

详见 `time_and_state.md`。

---

## F. 重复操作与一致性

| 触发器 | 必测项 | PRD 未写时 |
|--------|--------|------------|
| 提交/支付/下单类 | 连续双击/重复提交：幂等或明确报错 | 行为标待澄清 |
| 修改同一条数据 | 两次合法更新结果符合最后一次 | — |
| 并发（库存/秒杀/余额） | 标「（需环境）并发扣减」至少 1 条 | 不编造通过标准 |

---

## G. 错误与可用性

| 触发器 | 必测项 | PRD 未写时 |
|--------|--------|------------|
| 任一校验失败 | 错误信息指明字段；无堆栈泄露 | — |
| 依赖不可用（可选） | 标「（需环境）下游超时/失败」占位 | 专业版+附录性能/联调 |

---

## H. 接口契约（用户提供 OpenAPI 时叠加）

加载 `api_contract_supplement.md`，与 PRD 测试点合并；冲突以 **PRD 业务描述优先、契约补技术断言** 为原则。

---

## I. 非功能（默认不自动生成，按套餐开启）
