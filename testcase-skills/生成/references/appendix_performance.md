# 附录：性能与稳定性（可选套餐）

> 压测对象示例：**秒杀财务系统** `POST /api/seckill/{activity_id}/{product_id}`、`GET /api/products`。

**默认不加载**。当 PRD 写明 SLA、响应时间、并发量，或客户购买性能包时启用。

无指标时只输出 **待澄清占位**，不写具体毫秒数。

---

## 触发后建议检查点

| 类别 | 检查点示例 |
|------|------------|
| 响应时间 | GET /api/products P95 ≤ X ms（X 来自 PRD，否则待澄清） |
| 并发秒杀 | N 并发 customer 同时下单同一商品，仅售出库存数单成功（需 Redis+环境） |
| 数据量 | 商品 1 万条时分页仍 200（若 API 支持分页，否则跳过） |
| 稳定性 | 预热后连续下单 1 小时无 Redis 连接泄漏（需环境，长期项） |

---

## 输出格式

```markdown
## 性能附录（可选）

### N-P-01 商品列表响应时间（待澄清）
- 预发环境 100 并发 GET /api/products，P95 ≤ **【待产品确认】** ms

### N-P-02 秒杀下单并发（需环境）
- 100 并发 POST /api/seckill/{aid}/{pid}，成功数 ≤ 秒杀库存，无超卖
```

编号建议 `N-P-xx`，优先级通常 P2/P3，标签 `nfr,performance`。
