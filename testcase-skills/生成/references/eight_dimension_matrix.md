# 8 维度覆盖矩阵

本包 8 维度用例矩阵，覆盖正常+异常+边界+安全+权限+依赖+幂等。

---

## 8 维度定义

| 维度 | 名称 | 说明 | 示例 |
|------|------|------|------|
| **N** | Normal 正常 | 合法参数，期望成功 | 正确用户名+密码 → 登录成功 |
| **B** | Boundary 边界 | 边界值测试 | 密码空、密码 129 字符超长 |
| **T** | Type 类型 | 类型错误 | 字符串当整数、布尔当字符串 |
| **E** | Exception 异常 | 业务异常 | 密码错误 5 次 → 账号锁定 |
| **A** | Auth 权限 | 权限越权 | 普通用户访问 admin 接口 → 403 |
| **D** | Dependency 依赖 | 依赖链测试 | 未登录调下单 → 401；依赖顺序错误 |
| **I** | Idempotent 幂等 | 重复请求 | 连续点击支付 3 次 → 只生成 1 订单 |
| **S** | Security 安全 | 安全测试 | SQL 注入、XSS、无 Token 访问 |

---

## 优先级判定

| 优先级 | 判定条件 | 生成策略 |
|--------|----------|----------|
| **P0** | 路径含 order/seckill/pay/stock/confirm/cancel/approve 且是 POST/PUT/DELETE | 8 维度全覆盖 |
| **P1** | 其他写操作（POST/PUT/DELETE） | N/B/E/A 4 维度 |
| **P2** | 读操作（GET） | N/B 2 维度 |

---

## 生成示例（登录接口）

| 维度 | 用例标题 | 预期结果 |
|------|----------|----------|
| N | 正确手机号+密码登录 | 200，返回 token |
| B | 密码为空 | 400，提示密码不能为空 |
| B | 密码 129 字符（上限 128） | 400，提示密码超长 |
| T | 手机号传数字类型 | 400，提示格式错误 |
| E | 密码错误 5 次 | 403，提示账号锁定 30 分钟 |
| A | 无 Token 访问 /api/user/profile | 401 |
| D | 未登录调 /api/orders | 401 |
| I | 连续 3 次登录请求 | 只返回 1 个 token |
| S | 手机号传 SQL 注入 | 400，提示格式错误 |

---

## 使用方式

在 testcase-skills/生成/ 的 SKILL.md 中，Step 4 覆盖维度时引用此矩阵：

```
Step 4：覆盖维度
- P0 接口：N/B/T/E/A/D/I/S 8 维度全覆盖
- P1 接口：N/B/E/A 4 维度
- P2 接口：N/B 2 维度
```
