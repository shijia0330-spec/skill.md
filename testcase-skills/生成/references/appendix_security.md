# 附录：安全测试点（可选套餐）

> 示例接口来自 **秒杀财务系统**（JWT、`/api/products`、`/api/seckill/...`）。

**默认不加载**。当 PRD 写明安全要求、或客户购买安全附录、或系统处理订单/资金时，在 Step 4 末尾增加「安全附录」章节。

不编造超出系统类型的测试（如 PRD 无文件上传则不写上传漏洞用例）。

---

## 触发后建议检查点

| 类别 | 检查点示例 |
|------|------------|
| 认证 | 未登录 GET /api/auth/profile → 401；过期/篡改 JWT → 401 |
| 授权 | customer POST /api/products → 403；用户 A 查用户 B 的秒杀订单 → 403/404 |
| 注入 | 商品 `name` 含 `<script>alert(1)</script>`，存储或展示时转义 |
| 敏感信息 | 500 响应不含堆栈；登录响应不返回 password_hash |
| 暴力破解 | 若 PRD 有登录限流则测；否则标待澄清，不编造 OTP/KYC 场景 |

---

## 输出格式

```markdown
## 安全附录（可选）

### P-S-01 水平越权访问他人秒杀订单
- 用户 A（customer）已登录，将 GET /api/seckill/order/{id} 的 id 换为用户 B 的订单
- 返回 403 或 404，不返回 B 的订单金额与状态
```

编号建议 `P-S-xx`，优先级通常 P0/P1。
