## 一条常见流水线

需求文档 → **分析**（拆场景/边界） → **生成**（RAG 检索 → 覆盖矩阵 → 编号 → 评审表） → **评审**（查漏/改措辞） → 输出最终用例集。

## 核心能力

| 能力 | 位置 | 说明 |
|------|------|------|
| RAG 知识增强 | 生成/SKILL.md + rag_prefetch.py | BM25+向量检索项目文档，增强生成质量 |
| 8 维覆盖矩阵 | 生成/references/eight_dimension_matrix.md | 功能/边界/异常/性能/安全/兼容/易用/恢复 |
| 边界值速查 | 生成/references/boundary_value_testing.md | 阈值 -1/阈值/阈值+1 自动覆盖 |
| 用例编号 | 生成/references/delivery_standard.md | 统一编号规则，可追溯 |
| 评审表 | 评审/SKILL.md | 查漏/改措辞/排优先级 |
| 标题层级保留 | 生成/references/structure_preservation.md | 输出与 PRD 标题层级一致 |
